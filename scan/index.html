scan

hover-scannable Pink Trombone · flexible timing worklet: — bridge: —

Move across the strip to speak. Dwell on a phoneme and it holds — stops hold their closure (silent, or a voice bar for b d g) and fire the burst the moment you leave. Leave the strip to release.

tract

The upstream Pink Trombone view. Costs a little CPU; it also lets you grab the tract by hand while scanning.

control from Max (OSC over UDP)

Run node scan-bridge/scan-bridge.js from the repo root, then send OSC to 127.0.0.1:7400 from [udpsend 127.0.0.1 7400]. 

/scan/position 3.42     scan position, in cells (index + fraction)
/scan/norm 0.5          same thing, normalised 0..1
/scan/index 3           jump to the centre of cell 3
/scan/gate 1            1 = sound, 0 = release
/scan/note 60.5         pitch as a MIDI note number (fractional ok)
/scan/bend -2.          semitone offset
/scan/glide 0.05        portamento seconds
/scan/text "hello"      set the words
/scan/phonemes "hɛloʊ"  set IPA directly
/scan/param burstTime 0.012
/scan/tract 44          tract length
/scan/whisper 0
/scan/gain 1.

Feedback comes back on 127.0.0.1:7401 (/scan/out/cell, /scan/out/gesture) — listen with [udpreceive 7401].
